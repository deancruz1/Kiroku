# Kiroku | 記録

A full-stack anime tracker with seasonal calendar, personalized recommendations, and interactive stats.

## Tech Stack

Next.js 16 • TypeScript • Prisma • PostgreSQL • Tailwind CSS • shadcn/ui • NextAuth.js • TanStack Query • Recharts • Framer Motion • Jikan API

## Features

- Discord OAuth and email/password authentication
- Full CRUD watch list with episode tracking and star ratings
- 7-day seasonal broadcast calendar with countdown timers
- Personalized recommendation engine based on watch history
- Stats dashboard with interactive charts
- Custom collections
- Profile settings with account management
- Fully responsive
